Reset Ukuran Kotak berfungsi untuk mengembalikan ukuran kotak ke ukuran awal atau ukuran yang sudah ditentukan sebelumnya. Fitur ini berguna ketika ukuran kotak sudah diubah menjadi terlalu besar atau terlalu kecil sehingga pengguna dapat mengembalikannya dengan mudah tanpa harus mengatur ukurannya secara manual. Dengan adanya tombol Reset Ukuran Kotak, tampilan kotak dapat kembali seperti semula dengan lebih cepat dan praktis.

Token Warna dan Jarak digunakan untuk mengatur warna dan jarak pada tampilan halaman agar lebih rapi dan menarik. Contohnya, warna dapat digunakan untuk mengatur warna kotak atau tulisan, sedangkan jarak digunakan untuk mengatur jarak antar kotak, tulisan, atau bagian halaman.

TIPOGRAFI DAN UNIT Disini saya jadi mengetahui bagaimana cara menggunakan ataupun mengatur ukuran melalui rem. yang dimana pada program bagian ini juga berfungsi untuk membuat teks tida  terpotong saat kita  membesarkan halaman sampai zoom 200.
