pada praktikum ini, saya mengganti class cards menjadi catalog dan menggunakan CSS Grid untuk mengatur kartu menjadi beberapa kolom. Saya menguji tampilan pada ukuran layar 320px, 768px, dan 1200px untuk melihat perubahan jumlah kolom.

kemudian menggunakan Flexbox untuk menyusun judul, paragraf, dan link Detail pada setiap kartu. Saya juga mengatur jarak antarisi agar kartu terlihat rapi dan konsisten.

selanjutnya, saya memeriksa urutan HTML dan menguji tampilan dengan nol, satu, dan lima kartu. Saya memeriksa kode HTML dan CSS serta memastikan urutan fokus tetap mengikuti HTML.

hasilnya : Grid menyesuaikan ukuran layar, sedangkan Flexbox membuat isi kartu tersusun rapi.
